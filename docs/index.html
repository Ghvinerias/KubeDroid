// security

Your device. Your data.

No servers. No accounts. No telemetry. Everything stays on your device.

✓
Android Keystore encryption. Credentials encrypted at rest with AES-256-GCM.
✓
Biometric app lock. Fingerprint or face unlock. Auto-locks after 30s in background.
✓
Zero data collection. No analytics, no crash reporting, no tracking whatsoever.
✓
Backup exclusion. Credentials explicitly excluded from Android cloud backups.
✓
Biometric secret reveal. Kubernetes Secret values require auth. Auto-hide after 30s.
✓
No token persistence. Cloud access tokens held in memory only. Never written to disk.
